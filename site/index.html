An SSH client with FinalShell's layout and vertical session tabs

Server stats at the top left, sessions under them, the terminal on the right and the remote files below it. A native app written in Go, with no Java runtime to install.

Where the real Finallyshell is This page and the GitHub repository are the project's only official places, and GitHub Releases is the only official download. A site that offers downloads under the Finallyshell name is not affiliated with this project.

Remote files next to the terminal

Browse the server over SFTP under the terminal. Drag files in to upload, follow transfers as they run, and edit remote text files in the built-in editor.

See how the server is doing

CPU, memory, network, disks and processes of a Linux server, shown beside the session and read over the same connection.

Bring your hosts with you

Import connections and folders from FinalShell, Xshell, SecureCRT and MobaXterm, the hosts in your ~/.ssh/config, or a server list in a CSV or Excel file.

Commands one click away

Save the commands you type often as buttons, write a few lines in the command editor and send them, to one session or to several at once.
