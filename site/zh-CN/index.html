Finallyshell

布局和 FinalShell 一样、会话标签竖着排的 SSH 客户端。用 Go 写的原生程序，不需要装 Java。

从 GitHub Releases 下载 源代码
macOS · Windows · Linux
认准官方渠道 本页面和 GitHub 仓库是本项目仅有的官方渠道，GitHub Releases 是唯一的官方下载来源。以 Finallyshell 名义提供下载的其他网站都与本项目无关。

服务器上的文件就在终端下面

通过 SFTP 浏览服务器上的文件。把文件拖进来就能上传，传输进度随时可见，文本文件可以用内置编辑器直接改。

服务器状态一眼看清

Linux 服务器的 CPU、内存、网络、磁盘和进程显示在会话旁边，走的是同一个连接。

原来的服务器直接带过来

可以导入 FinalShell、Xshell、SecureCRT、MobaXterm 的连接和文件夹，~/.ssh/config 里的主机，或者 CSV、Excel 格式的服务器列表。

常用命令点一下就发

把常用的命令存成按钮，或者在命令编辑器里写几行直接发送，可以发给一个会话，也可以同时发给多个。
